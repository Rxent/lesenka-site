# Студия творчества и развития «Лесенка» — лендинг

Адаптивный одностраничный сайт-визитка для детской Студии творчества и развития «Лесенка». Реализован на чистом HTML5, CSS3 (Flexbox/Grid) и минимальном JavaScript без внешних зависимостей и сборщиков — открыть `index.html` достаточно для запуска.

## Стек

- HTML5 (семантическая разметка: `header`, `main`, `section`, `article`, `nav`, `footer`)
- CSS3 (CSS-переменные, Flexbox, Grid, медиа-запросы, анимации)
- Vanilla JavaScript (IntersectionObserver для появления при скролле, мобильное меню, валидация формы, маска телефона)
- Шрифты Google Fonts: Comfortaa (заголовки), Nunito (основной текст)
- Иконки направлений — инлайн SVG (без сторонних библиотек)

## Запуск

Никакой сборки не нужно — это статический сайт.

```bash
# вариант 1: открыть index.html в браузере
xdg-open index.html      # Linux
open index.html          # macOS
start index.html         # Windows

# вариант 2: локальный сервер (рекомендуется, чтобы корректно работали якоря и SVG)
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Что реализовано

Согласно ТЗ:

- **Шапка** — логотип (лисёнок Лесик + текст «Лесенка») и меню-якоря: «О студии», «Направления», «Наши ценности», «Записаться». Sticky-header с подсветкой при скролле и адаптивным бургер-меню.
- **Первый экран (Hero)** — заголовок, подзаголовок, дружелюбная иллюстрация лисёнка Лесика и CTA-кнопка «Найти любимое дело», ведущая к форме записи.
- **О студии** — описание философии и цитата «Каждый талант — это дар, который нужно поддержать и развивать с любовью».
- **Направления занятий** — сетка из 10 карточек с иконками: лепка, ИЗО, авторская кукла, театр, танцы и музыка, сценическая речь и вокал, гитара, окружающий мир, подготовка к школе, ранняя профориентация.
- **Наши ценности / Преимущества** — индивидуальный подход, тёплая атмосфера, философия «талант — это дар».
- **Контакты / форма** — поля «Имя родителя» и «Номер телефона» (с маской и валидацией), адрес, телефон, иконки соцсетей.
- **Подвал** — копирайт и кнопка «наверх».

Технические требования:

- Семантическая HTML-разметка для SEO и скринридеров (`<header>`, `<main>`, `<section>`, `<article>`, `<nav>`, `<footer>`, корректные уровни заголовков, `aria-*`, skip-link).
- Оптимизированные изображения — все иллюстрации в формате SVG (масштабируются без потерь, размер в килобайтах).
- Кастомные шрифты через Google Fonts (`preconnect` для ускорения).
- Фавикон в SVG.
- Валидный код без критических ошибок в консоли.
- Поддержка `prefers-reduced-motion` — анимации отключаются у пользователей с настройкой «уменьшить движение».
- Адаптив от 320px до 1440px+ на CSS Grid и Flexbox.

## Цветовая гамма и типографика

Тёплая, солнечная палитра природных тонов:

| Назначение               | Цвет        | HEX       |
| ------------------------ | ----------- | --------- |
| Основной (как у лисёнка) | оранжевый   | `#F4A24B` |
| Акцент (тёмно-оранжевый) | оранжевый+  | `#E8782C` |
| Дополнительный           | мягкий зелёный | `#8FBE74` |
| Фон                      | бежевый     | `#FFF6EB` |
| Текст                    | тёмный      | `#2D2A26` |

Анимации имитируют «движение вверх по лесенке» — плавное появление блоков при прокрутке через IntersectionObserver, лёгкое покачивание hero-иллюстрации и плавающие фоновые блобы.

## Замена контента и материалов

Текущие иллюстрации — временные плейсхолдеры. Чтобы заменить на финальные материалы:

1. **Логотип** — положите файл лисёнка Лесика в `assets/images/logo-lesik.svg` (или замените на `.png`/`.webp` и поправьте `src` в `index.html`, в шапке и футере).
2. **Hero-иллюстрация** — положите финальный баннер в `assets/images/lesik-hero.svg`. Рекомендуемый размер исходника: **1920×900 px** (16:9, JPEG/WebP ≤ 500 КБ) для full-width баннера или **1200×600 px** для карточки.
3. **Фавикон** — `assets/icons/favicon.svg` (можно также добавить `favicon.png` 32×32 для совместимости).
4. **Контакты** — в `index.html` найдите блок `.contact__info` и подставьте реальный адрес, телефон (`href="tel:..."`) и ссылки на соцсети.
